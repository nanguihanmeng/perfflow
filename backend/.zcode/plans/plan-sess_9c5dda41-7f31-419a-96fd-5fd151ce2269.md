## 考核表逻辑重构方案（5 项需求）

### 需求理解与现状差异

| # | 需求 | 现状 | 改动方向 |
|---|---|---|---|
| 1 | 考核明细 HR 用 Excel 导入，员工不手填 | 明细由员工在页面手填 | 新增 HR 导入 Excel；员工只填完成率 |
| 2 | 自评得分 0-100 | 完成率允许 0-150，得分可超指标分 | 完成率改为 **0-100**（保证得分≤指标分、总分≤100） |
| 3 | 行结果更名"考核结果"，任何人不可读写，只跟总分相关；总分=50%自评+50%领导；A 90-100/B 75-90/C 60-75/D <60 | 行结果是可填自由文本；等级阈值 A≥90/B≥80/C≥70/D<70 | 删除行级 rowResult 读写；改阈值；主表只显示一个考核结果 |
| 4 | 取消调整得分，部门领导在自评得分里改 | adjustedScore 调分链路 + 必填 remark | 删除 adjustedScore 全链路；DEPT_REVIEW 阶段部门领导直接改完成率 |
| 5 | 考核表格式与某公司.xlsx A1:G16 一致 | 现有 el-table 列表式 | 页面+导出改为模板布局 |

### 模板结构（已分析桌面某公司.xlsx）
标题行 → 信息栏(部门/被考核人/岗位/部门负责人) → 考核期/填表日期 → 表头(序号/指标类别/指标名称/指标分数/工作目标/评分标准) → 10行数据(5行日常工作80分 + 2行开放型20分 + 3行加减分项) → 总分行 → 签字栏

### 数据库（1 个 ALTER，不动现有表结构数据）
- `assessment_table` 加列 `position VARCHAR(50) NULL`（岗位，被考核人在考核表页面填；部门/被考核人/部门负责人从 sys_department.name/sys_user.realname/dept_lead 带出）
- `assessment_row` 的 `adjusted_score/adjust_remark/row_result` 列保留但停用（不读写，避免破坏历史数据）

### 后端改动
1. **AssessmentCalcService**：`recalc` 去掉 adjustedScore 逻辑（总分=Σ非BONUS行 selfScore）；`gradeOf` 阈值改 A≥90/B≥75/C≥60/D<60；`finalizeWithLeaderScore` 保持 0.5/0.5
2. **AssessmentRowService**：员工更新只允许 completionRate(0-100)+岗位；每次更新后立即 `recalc` 刷新总分；**删除 adjustByDeptLead**；新增部门领导改完成率（DEPT_REVIEW 阶段）
3. **AssessmentTableService.submit**：校验改为"完成率已填(0-100)+HR 已导入指标"，删除 completionRate 超150 约束
4. **新增 AssessmentImportService**（Hutool ExcelReader，复用已有 hutool-poi）：解析上传 xlsx 的序号1-10行 → 指标类别/指标名称/指标分数/工作目标/评分标准，按 seq 覆盖写 assessment_row，幂等
5. **AssessmentExportService**：导出/打印改成模板 A1:G16 格式（标题/信息栏/考核期/表头+10行含完成率与自评得分/总分/签字栏）
6. **Controller**：删除 `adjust` 端点；`update` 端点权限放宽为登录（service 内按角色+状态判 EMP 填/DEPT_LEAD 改）；新增 `POST /assessment-tables/{id}/import`（HR，multipart）；删除 RowAdjustReq

### 前端改动
1. **AssessmentRows.vue 重做**为模板 A1:G16 布局：信息栏（岗位可填）、考核期、表头（序号/类别/指标名称/指标分数/工作目标/评分标准/完成率/自评得分）、10行分组、总分行、签字栏；删除调整得分列/行结果列/调分按钮/调分对话框；完成率输入 0-100；自评得分只读展示
2. **AssessmentDetail.vue**：删除 canAdjust；canEditRows 按 EMP(SELF_DRAFTING) 或 DEPT_LEAD(DEPT_REVIEW) 判断；提交校验提示更新；grade 显示更名为"考核结果"
3. **API**：删 adjustRowApi；RowReq 只留 completionRate/position；新增 importApi；RowResp 去掉 rowResult/adjustedScore
4. **HR 考核列表/详情**：加"导入 Excel"上传按钮（模板格式）
5. **dto.ts** 同步字段

### 验证
- 后端单测更新：gradeOf 新阈值（90/75/60 边界）、recalc 无 adjustedScore
- 全链路 curl：HR 导入 Excel → 员工填完成率 → 提交 → 部门领导改完成率 → 领导评分 → 验证总分=50/50、等级边界
- 前端 vue-tsc + 浏览器实测模板布局与导入流程
- 打包重启，清理测试数据

不改数据库既有表结构（仅加 position 列），不新增依赖（复用 hutool-poi）。
